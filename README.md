# AI Sales Agent

A conversational sales assistant for a fictional computer-equipment store, built around LLM function calling. The agent answers store questions with retrieval-augmented generation, recommends products from a database, books consultations through Calendly and creates Stripe payment links.

## Overview

The agent, named Emily, represents the store "TechNerds". A custom `Agent` class sends the conversation to a model through LiteLLM, lets the model call registered tools, and feeds tool results back until a final reply is produced. The system prompt defines a sales procedure, including confirming order details and checking shipping availability before any payment link is generated.

## Features

- Command-line chat with a tool-using sales agent
- Store information lookup using hybrid search (semantic plus BM25) over a knowledge file
- Product recommendations from a SQLite catalogue, with the search query generated by the model
- Calendly scheduling link generation for expert consultations
- Stripe Checkout link generation for confirmed purchases
- Model-agnostic: the model is set in `main.py` and can be any LiteLLM-supported provider

## Getting Started

### Prerequisites

- Python 3.10 or later
- API keys for Groq, Google AI (embeddings), Calendly and Stripe

### Installation

```bash
git clone https://github.com/mosesaderemi/ai-sales-agent.git
cd ai-sales-agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

On macOS or Linux activate with `source .venv/bin/activate`.

### Configuration

Copy `.env.example` to `.env` and fill in the values:

| Variable | Purpose |
| --- | --- |
| `GROQ_API_KEY` | Language model access through Groq |
| `GOOGLE_API_KEY` | Embeddings used to build and query the vector index |
| `CALENDLY_API_KEY` | Creating scheduling links |
| `CALENDLY_EVENT_TYPE_UUID` | Calendly event type to book |
| `STRIPE_API_KEY` | Creating checkout sessions |
| `LANGFUSE_*` | Optional tracing |

The Stripe price IDs in `scripts/products_list.py` must be replaced with price IDs from your own Stripe account.

### Prepare the data

Run both commands from the project root:

```bash
python scripts/create_database.py
python -m scripts.create_index
```

The first creates `database.db` with the product catalogue. The second builds the vector index in a local `db` folder from `files/Docs.txt`.

### Run

```bash
python main.py
```

Type a message to chat and `exit` to quit.

## How a Conversation Works

1. The user message and the system prompt are sent to the model along with the tool schemas.
2. The model either replies or requests a tool call.
3. Requested tools run and their output is appended to the conversation.
4. The loop repeats until the model returns a final answer.

## Security Notes

- Never commit your `.env` file. It is excluded by `.gitignore`.
- Use Stripe test keys while developing.
